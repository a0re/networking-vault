# Wireless Security

## Evil Twin Access Point Attack

[Insert diagram: evil twin attack - rogue AP with same SSID intercepting traffic between client and legitimate AP]

- Man-in-the-middle type attack where a rogue access point configures to the same SSID as a legitimate access point (AP).

- Used in public areas with WiFi.
- Sometimes unnoticed and return traffic from legitimate access points is sent to the rogue access point (AP).

## WEP

- 1st generation authentication (OBSOLETE).

## WPA

- TKIP encryption.
- Uses MIC integrity.

## Enterprise

- Uses user accounts (RADIUS) Remote Authentication Dial-In User Service.
- Authenticate with 802.1X standard.
- Per user security.
